랜딩페이지 이벤트 사전

탐색(Explore) 표에 뜨는 이벤트 이름 값이 무엇을 뜻하는지 빠르게 확인하는 용도. GA4 창 옆에 띄워두고 참고할 것.

이벤트명 한글 표기 발생 시점 · 의미 상태
기본 자동 수집 — 항상 찍힘
page_view 페이지 보기 화면이 로딩될 때마다 발생. 새로고침·재방문 시 중복 카운트됨. 확인됨
first_visit 첫 방문 이 브라우저로 처음 방문한 순간. 평생 딱 1번만 발생 — 그래서 사용자 수와 세션수가 항상 같음. 확인됨
session_start 세션 시작 한 번의 방문(세션)이 시작되는 순간. 30분 이상 활동이 없으면 다음 활동은 새 방문으로 분리됨. 확인됨
user_engagement 사용자 참여 탭이 포커스된 채로 10초 이상 머물렀거나, 조회 2회 이상 등 조건 충족 시 발생. 확인됨
향상된 측정 — 요소가 있을 때 자동 수집
scroll 스크롤 페이지를 90% 이상 내렸을 때 발생. 확인됨
form_start 양식 시작 입력창에 커서를 찍고 입력을 시작했을 때 발생. 확인됨
form_submit 양식 제출 GA4가 폼 제출을 범용적으로 감지. submit_application과 별개 이벤트. 미확인
click 클릭 다른 사이트로 연결되는 링크 클릭 시 발생. 외부 링크가 있을 때만 해당. 미해당
file_download 파일 다운로드 다운로드 링크 클릭 시 발생. 다운로드 요소가 있을 때만 해당. 미해당
video_start /
video_progress /
video_complete		 동영상 시작 /
진행 /
완료		 삽입된 영상 재생·시청 단계별 발생. 영상이 있을 때만 해당. 미해당
직접 추가한 맞춤 이벤트
submit_application 신청서 제출 제출 버튼을 눌러 최종 제출에 성공했을 때만 발생. 전환으로 등록 예정인 핵심 지표. 맞춤 · 처리중
확인됨 — 실제 실시간/탐색 데이터에서 발생이 이미 확인된 이벤트
맞춤 · 처리중 — 직접 코드에 추가한 이벤트. 발생은 했으나 GA4 처리 지연(1~2일) 대기 중
미확인 / 미해당 — 아직 데이터로 확인 안 됐거나, 현재 랜딩 구조상(외부 링크·다운로드·영상 없음) 발생할 요소 자체가 없음
활성 사용자

그 이벤트를 한 번이라도 발생시킨 고유 인원 수. 같은 사람이 여러 번 해도 1명으로 카운트.

세션수

그 이벤트가 발생한 방문(세션) 횟수. 같은 사람이 다른 시간대에 재방문하면 늘어남.
